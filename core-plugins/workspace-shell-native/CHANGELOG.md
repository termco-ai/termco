# Changelog

## 1.0.2

- Keep pane drag previews above native browser content, including when moving a pane across the browser.
- Keep split headers and terminal surfaces opaque beside a live browser so old titles, chat positions, and other window content cannot show through them.

Ships with Termco 0.9.12 through the application update.

## 1.0.1

- Arrange files and terminals in horizontal or vertical panes and restore their orientation and order with the workspace.
- Drag either placed pane by its title bar to another edge, with a placement preview and Escape cancellation.
- Keep editor buffers, undo history, and running terminal sessions intact when rearranging panes.
- Open a terminal below the focused file through the command palette, and route pane focus, close actions, and shortcuts consistently.

Ships with Termco 0.9.11 through the application update.
